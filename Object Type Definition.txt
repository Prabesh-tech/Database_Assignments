What are the two types of objects?

The two types of objects in Oracle are:

Object Types (structure/template definitions)
Object Tables (tables that store actual object data)






What do you call an ERD that includes objects?

An ERD that includes objects is called an Object-Relational ERD (OR-ERD).






What is the additional syntax needed at the end of an object definition?

The additional syntax is:

/







Why is the additional syntax needed?

The / is used to execute and compile the object type definition in SQL*Plus and mark the end of the definition block.







Why can you include ‘OR REPLACE’ in a type definition?

OR REPLACE allows you to modify an existing object type without dropping it first. It replaces the old version and avoids dependency errors.







What information will be displayed if you query a REF column using the traditional style?

It will display the object reference (OID/pointer) that points to the row in the object table, not the actual data.
